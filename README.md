# Riesgo-cardio-reno-metabolico
SISTEMA PREDICTIVO BASADO EN INTELIGENCIA ARTIFICIAL Y METODOLOGÍA DIALYSIS PARA IDENTIFICACIÓN Y SEGUIMIENTO DEL RIESGO CARDIO-RENO-METABÓLICO  Analisis Predictivo con Machine Learning Dataset: Hipertensión Arterial México (ENSANUT 2022) — 4,363 registros

#Limitaciones
* Dado que la variable objetivo riesgo_hipertension fue proporcionada por el conjunto de datos original, no puede descartarse completamente que parte de su construcción haya incorporado información relacionada con la presión arterial. 
* El estudio se desarrolló utilizando una única fuente de datos.
* No se realizó validación externa en otra cohorte.
* Los hallazgos relacionados con temperatura ambiental deben considerarse exploratorios.
